# Swoopa
Swoopa - веб-приложение позволяющее пользователям размещать объявления о предоставлении услуг и товаров с обменом или без. 

## Описание проекта
Данный проект был создан для переиспользования потерявших нужду вещей и для людей, которые не могут себе позволить определенный вид товаров или услуг, будь то финансово или физически, благодаря бартеру и возможности договориться об удобной обеим сторонам (продавцу и покупателю) цене.

Ключевые функции приложения:
- Регистрация по почте, именем пользователя с выбором города проживания.
- Просмотр ленты объявлений
- Поиск по объявлениям
- Добавление объявлений в избранное
- Функция чата с авторами объявления

Приложение актуально для любого заинтересованного лица, вне зависимости от возраста. Предварительно можно сказать, что больший спрос будет среди школьников, студентов, пожилых людей и тех, чьи возможности физически или финансово ограничены.
Основное преимущество данного приложения это бартер - возможность обмена товаров и услуг.

## Стек технологий
Backend: Python, Django\
Frontend: React, HTML + Tailwind CSS, TypeScript, AntDesign, Vite\
Database: PostgreSQL\
Deployment: Docker

## Инструкция по запуску проекта
Предварительные требования: установка Docker и его открытие
Пошаговая установка: 
1. Клонирование репозитория: ```git clone https://github.com/altngg/Swoopa.git```
2. Перейти в директорию: ```cd Swoopa```
3. Запуск докера: ```docker compose up --build```
